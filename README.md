# 星间塔罗

免费、无账户的静态塔罗体验站：[在线测试](https://jia-hq.github.io/ceshi/)。提供一张、三张、五张牌阵，78 张牌义百科，以及仅保存在当前浏览器中的历史记录。

## 使用

打开网站，选择牌阵与主题，可填写一个开放式问题或直接抽牌。结果包含牌位、正逆位、逐张解读、整体线索与反思问题。牌义百科支持按大阿卡那与四种花色筛选，也可以搜索牌名和关键词。

本项目是静态网站，可由 GitHub Pages 从 `main` 分支根目录直接发布。在本地可用任意静态服务器预览，例如 `npx serve .`。运行核心测试：`node --test core.test.mjs`。

## 隐私

没有账户、支付或在线解读接口。问题、抽牌结果及最近 30 条记录只保存在当前浏览器的 `localStorage`。在“我的记录”中可删除单条或清空全部记录。复制摘要不会包含原问题。请不要在问题中填写姓名、电话等私人信息。

塔罗解读用于娱乐和自我反思，不替代医疗、法律、财务或其他专业建议。

## 开源来源

78 张牌的英文名称和分类基础数据来自 [metabismuth/tarot-json](https://github.com/metabismuth/tarot-json)，MIT 许可证见 `THIRD_PARTY_LICENSE.txt`。本站没有使用该项目的扫描牌图。中文牌名、牌义、抽牌逻辑和界面由本项目编写。视觉上参考了成熟塔罗网站对牌阵、牌义和记录的组织方式，没有复制其图片或文案。
