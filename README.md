# 星间塔罗

免费、无账户的静态塔罗体验站：[在线测试](https://jia-hq.github.io/ceshi/)。提供一张、三张、五张牌阵，78 张牌义百科，以及仅保存在当前浏览器中的历史记录。

## 使用

打开网站，选择牌阵与主题，可填写一个开放式问题或直接抽牌。结果包含牌位、正逆位、逐张解读、整体线索与反思问题。牌义百科支持按大阿卡那与四种花色筛选，也可以搜索牌名和关键词。

三种牌阵具有不同的节奏：一张牌聚焦翻开并给简短启示；三张牌扇形展开，并用“处境与提醒、可以尝试”两段串联；五张牌依次展开，分别解释问题核心、资源与阻力、新视角、行动与整合。动画会遵循设备的“减少动态效果”设置。

本项目是静态网站，可由 GitHub Pages 从 `main` 分支根目录直接发布。在本地可用任意静态服务器预览，例如 `npx serve .`。运行核心测试：`node --test core.test.mjs`。

## 隐私

没有账户、支付或在线解读接口。问题、抽牌结果及最近 30 条记录只保存在当前浏览器的 `localStorage`。在“我的记录”中可删除单条或清空全部记录。复制摘要不会包含原问题。请不要在问题中填写姓名、电话等私人信息。

塔罗解读用于娱乐和自我反思，不替代医疗、法律、财务或其他专业建议。

## 开源来源

78 张牌的英文名称、分类基础数据及 Rider–Waite–Smith 牌面扫描图来自 [metabismuth/tarot-json](https://github.com/metabismuth/tarot-json)，仓库的 MIT 许可证见 `THIRD_PARTY_LICENSE.txt`。原仓库说明扫描图来自 data.totl.net，并提醒牌图在不同地区的版权状态可能不同；公开推广前应按面向地区再次核实图像权利。本站保留来源说明，不把扫描图声明为本站原创。中文牌名、牌义、抽牌逻辑和界面由本项目编写。

解读采用本地规则：结合牌义、牌位、正逆位、主题，以及问题中的常见焦点（如沟通、边界、选择、工作）。问题文本不会发送给外部模型。这种方式能让解读贴近一部分具体问题，但不能理解所有自然语言；不匹配的提问会退回主题解读。

## 心理与塔罗知识库

[知识库与书目](docs/knowledge/README.md)记录了已核对的开放资料、已确认但尚未纳入的现代书籍，以及产品采用的提问和回应规则。新版本会先回应明显的情绪，再提供牌面视角、反思问题和可选择的小行动。无法识别的具体问题会明确提示理解有限。它不进行心理测评、诊断或治疗。
